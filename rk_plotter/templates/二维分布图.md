![[Pasted image 20260520003516.png]] 一、图像类型识别与结构拆解

这是一张**三面板二维相空间等值填色图 / 联合概率密度图 / 条件平均场图**。

```text
a：JPDF 联合概率密度分布图，红色对数色标
b：δ/f 条件平均分布图，蓝-白-红发散色标
c：∇T 条件平均分布图，蓝-白-黄-红连续色标
```

图像核心结构：

- 横轴：`ζ/f`
    
- 纵轴：`α/f`
    
- 三个子图共用相同坐标范围，大约为：
    
    - x：`-1.0 ~ 2.0`
        
    - y：`0 ~ 2.0`
        
- 每个子图都有：
    
    - 彩色填色场
        
    - 黑色等值线
        
    - 稀疏黑色散点 / 轮廓边界点
        
    - 白色虚线参考等值线
        
- Panel a：
    
    - 红色系表示 `JPDF`
        
    - 色标为对数尺度
        
    - 绿色虚线椭圆表示一个主要概率集中区
        
- Panel b：
    
    - 色标变量为 `δ/f`
        
    - 蓝色为负值，红色为正值
        
- Panel c：
    
    - 色标变量为 `∇T`
        
    - 蓝色低值，黄色/红色高值

## 二、单独的虚拟数据生成代码

```python
import numpy as np
import pandas as pd


def generate_phase_space_points(seed=42, n=120000):
    """
    生成类似原图的相空间点云数据。
    
    字段：
    zeta_f : 横轴 ζ/f
    alpha_f: 纵轴 α/f
    delta_f: panel b 的条件变量 δ/f
    gradT  : panel c 的条件变量 ∇T
    """

    rng = np.random.default_rng(seed)

    # 主体相空间：x 服从偏态分布，范围约 -1 到 2
    x1 = rng.normal(0.15, 0.45, int(n * 0.55))
    x2 = rng.normal(0.85, 0.42, int(n * 0.35))
    x3 = rng.normal(-0.45, 0.18, n - len(x1) - len(x2))
    x = np.concatenate([x1, x2, x3])
    rng.shuffle(x)
    x = np.clip(x, -1.0, 2.0)

    # 构造 U 型 / 楔形主骨架
    lower = 0.08 + 0.22 * (x + 0.1) ** 2
    upper = 0.55 + 0.38 * (x + 0.15) ** 2 + 0.18 * x

    # 相空间内部位置参数，偏向低 alpha 区域
    t = rng.beta(1.3, 3.3, size=n)
    y = lower + t * (upper - lower)

    # 加入噪声，增强自然边界
    y += rng.normal(0, 0.09 + 0.06 * np.clip(x, 0, None), size=n)

    # 左上分支，使图像在 x<0 区域具有向上弯曲的尾部
    left = x < -0.35
    y[left] += 0.35 * np.exp(-((x[left] + 0.75) / 0.22) ** 2)

    # 右上分支，使图像向右上角延伸
    right = x > 0.6
    y[right] += 0.35 * (x[right] - 0.6)

    y = np.clip(y, 0.0, 2.0)

    # panel b: δ/f，整体右上区域更负，左侧局部略正
    delta_f = (
        -0.10
        - 0.16 * x
        - 0.08 * y
        + 0.30 * np.exp(-((x + 0.75) / 0.23) ** 2 - ((y - 0.75) / 0.35) ** 2)
        + rng.normal(0, 0.04, n)
    )
    delta_f = np.clip(delta_f, -0.45, 0.28)

    # panel c: ∇T，随 x 和 y 增大而增强
    gradT = (
        0.25
        + 0.65 * (x + 1.0)
        + 0.65 * y
        + 0.55 * np.exp(-((x - 1.25) / 0.42) ** 2 - ((y - 1.35) / 0.35) ** 2)
        + rng.normal(0, 0.18, n)
    )
    gradT = np.clip(gradT, 0.0, 3.4)

    df = pd.DataFrame({
        "zeta_f": x,
        "alpha_f": y,
        "delta_f": delta_f,
        "gradT": gradT
    })

    return df


if __name__ == "__main__":
    df = generate_phase_space_points()
    df.to_csv("virtual_phase_space_data.csv", index=False)
    print(df.head())
```

def binned_fields(df, x_col, y_col, value_col=None,
                  xlim=(-1, 2), ylim=(0, 2),
                  nx=230, ny=170, smooth=1.4):
    """
    计算二维直方图密度以及条件平均场。
    """

    x = df[x_col].to_numpy()
    y = df[y_col].to_numpy()

    x_edges = np.linspace(xlim[0], xlim[1], nx + 1)
    y_edges = np.linspace(ylim[0], ylim[1], ny + 1)

    counts, _, _ = np.histogram2d(x, y, bins=[x_edges, y_edges])
    counts = counts.T

    counts_s = gaussian_filter(counts, sigma=smooth)

    x_centers = 0.5 * (x_edges[:-1] + x_edges[1:])
    y_centers = 0.5 * (y_edges[:-1] + y_edges[1:])
    X, Y = np.meshgrid(x_centers, y_centers)

    if value_col is None:
        return X, Y, counts_s

    values = df[value_col].to_numpy()
    weighted, _, _ = np.histogram2d(x, y, bins=[x_edges, y_edges], weights=values)
    weighted = weighted.T
    weighted_s = gaussian_filter(weighted, sigma=smooth)

    with np.errstate(divide="ignore", invalid="ignore"):
        mean_field = weighted_s / counts_s

    mean_field[counts_s < 3] = np.nan

    return X, Y, mean_field, counts_s
