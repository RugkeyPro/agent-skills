一、图像类型识别与结构拆解

这是一张**三面板组合科研图**，包含三种不同图型：

```text
c：双横轴水平条形图 / 分组水平柱状图
d：多类别堆叠面积图
e：双对数散点验证图 / Model-Observation 对比图
```

图像核心结构如下：

- **Panel c**：不同海区或流域的 Hg 与 MeHg 输出量对比
    
    - y 轴：区域名称
        
    - 下方 x 轴：`MeHg export (kg yr⁻¹)`
        
    - 上方 x 轴：`Hg export (Mg yr⁻¹)`
        
    - 实心柱表示 `Hg`，斜线填充柱表示 `MeHg`
        
    - 带水平误差线
        
- **Panel d**：不同区域逐月河流 Hg 输出的堆叠面积图
    
    - x 轴：月份
        
    - y 轴：`Riverine Hg export (Mg month⁻¹)`
        
    - 多个区域堆叠，总量在 8–9 月达到峰值
        
- **Panel e**：模型值与观测值对比
    
    - x 轴：`Model (kg yr⁻¹)`，log scale
        
    - y 轴：`Observation (kg yr⁻¹)`，log scale
        
    - 黑色对角线：`1:1` 参考线
        
    - 不同颜色和形状表示不同大洲
        
    - 部分点带误差棒
        
    - 标注了 `Amazon` 和 `Yangtze`

```python
import numpy as np
import pandas as pd


def generate_panel_c_data():
    """
    Panel c：生成 Hg 与 MeHg 年输出量数据。

    """
    regions = [
        "South Atlantic", "Indian", "South Pacific", "North Pacific",
        "North Atlantic", "Mediterranean", "Arctic", "Inland", "Southern Ocean"

        "MeHg_kg_yr": [3950, 1650, 1850, 900, 620, 360, 420, 80, 45],

            "#72c7ec", "#b7e0f7", "#ffb3b7", "#86c65a", "#f6c9cf"

    })

    return data


def generate_panel_d_data():

        "North Pacific":  [1,  1,  1,  1,  1,  2,  2,  3,  3,  2,  1,  1],
        "Inland":         [1,  1,  1,  1,  1,  1,  1,  1,  2,  1,  1,  1],
    })

    return data


def generate_panel_e_data(seed=7):
    """
    Panel e：生成 Model-Observation 双对数散点数据。
    """
    rng = np.random.default_rng(seed)

    groups = {
        "South America": {"n": 3,  "marker": "s", "color": "#6ec6e8", "range": (2.0, 5.5)},
        "North America": {"n": 26, "marker": "o", "color": "#f5a21a", "range": (1.0, 4.5)},
        "Europe":        {"n": 5,  "marker": "D", "color": "#e6e6e6", "range": (0.2, 3.0)},
        "Asia":          {"n": 18, "marker": "^", "color": "#f29a9a", "range": (1.2, 4.8)},
        "Africa":        {"n": 3,  "marker": "o", "color": "#a8d7ef", "range": (1.5, 3.4)},
    }

    rows = []

    for group, info in groups.items():
        logx = rng.uniform(info["range"][0], info["range"][1], info["n"])
        model = 10 ** logx

        noise = rng.normal(0, 0.38, info["n"])
        obs = 10 ** (logx + noise)

        for x, y in zip(model, obs):
            rows.append({
                "continent": group,
                "model": x,
                "observation": y,
                "marker": info["marker"],
                "color": info["color"],
                "xerr": x * rng.uniform(0.0, 0.35),
                "yerr": y * rng.uniform(0.0, 0.70)
            })

    df = pd.DataFrame(rows)

    # 强制加入两个标注点
    extra = pd.DataFrame([
        {
            "continent": "South America",
            "model": 2.2e5,
            "observation": 3.2e5,
            "marker": "s",
            "color": "#6ec6e8",
            "xerr": 1.2e5,
            "yerr": 2.7e5,
            "label": "Amazon"
        },
        {
            "continent": "Asia",
            "model": 5.0e4,
            "observation": 4.5e4,
            "marker": "^",
            "color": "#f29a9a",
            "xerr": 0.0,
            "yerr": 1.0e4,
            "label": "Yangtze"
        }
    ])

    df["label"] = ""
    df = pd.concat([df, extra], ignore_index=True)

    return df


if __name__ == "__main__":
    panel_c = generate_panel_c_data()
    panel_d = generate_panel_d_data()
    panel_e = generate_panel_e_data()

    panel_c.to_csv("panel_c_export.csv", index=False)
    panel_d.to_csv("panel_d_monthly_export.csv", index=False)
    panel_e.to_csv("panel_e_model_observation.csv", index=False)

    print(panel_c)
    print(panel_d.head())
    print(panel_e.head())
```

## 四、可调整参数说明

Panel c 中上下两个横轴的换算关系由这里控制：

```python
max_mehg = 5000
max_hg = 480
scale_hg_to_mehg_axis = max_mehg / max_hg
```

如果要让 Hg 实心柱更长或更短，只需要修改 `Hg_Mg_yr` 或 `max_hg`。

Panel d 的堆叠顺序由这里控制：

```python
stack_order = [
    "South Atlantic",
    "South Pacific",
    "Indian",
    "Mediterranean",
    "North Atlantic",
    "Southern Ocean",
    "Arctic",
    "North Pacific",
    "Inland",

```

Panel e 中对数坐标范围由这里控制：

```python
ax_e.set_xlim(1, 1e6)
```
