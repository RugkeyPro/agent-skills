一、图像类型识别与结构拆解

这是一张**双面板时间序列折线图 / 干预期标注时间序列图**，用于比较 2017–2022 年间工业捕捞船舶检测数量的变化。

图像结构：

```text
Panel a：Industrial fishing
上图：Outside China
下图：Inside China
横轴：Year，2017–2022
纵轴：Number of detected vessels in the ocean
紫色折线：周尺度或月尺度船舶检测数量
紫色虚线：长期均值
灰色背景块：对比基准期或统计窗口
黑色水平线 + Pandemic：疫情阶段标注
底部彩色短条：特定时间窗口 / 管理期 / 季节性标记
```

主要视觉特征：

- 上下两个时间序列子图共享年份横轴。
    
- 紫色折线具有明显季节性波动。
    
- 上图均值线约为 `19,200`，下图均值线约为 `7,900`。
    
- 疫情期后，折线整体相对均值降低，并标注 `−14 ± 2%` 和 `−8 ± 3%`。
    
- 左侧 y 轴采用文字化刻度：`Max.`、`Mean`、`Min.` 与具体数值组合。
    
- 下方使用绿色、红色、蓝紫色短条表示不同事件或季节窗口。

## 二、单独的虚拟数据生成代码

```python
import numpy as np
import pandas as pd


def generate_industrial_fishing_timeseries(seed=42):
    """
    生成用于复现图像的虚拟时间序列数据。

    字段说明：
    date: 周尺度日期
    outside_china: 中国以外海域工业捕捞船舶检测数量
    inside_china: 中国以内海域工业捕捞船舶检测数量
    """

    rng = np.random.default_rng(seed)

    dates = pd.date_range("2017-01-01", "2021-12-31", freq="W")
    t = np.arange(len(dates))
    year_float = dates.year + (dates.dayofyear - 1) / 365.25

    # =========================
    # Outside China
    # =========================
    outside = (
        19200
        + 2100 * np.sin(2 * np.pi * (year_float - 2017.15))
        + 1300 * np.sin(4 * np.pi * (year_float - 2017.05))
        + 600 * np.sin(10 * np.pi * year_float)
        + rng.normal(0, 420, len(dates))
    )

    # 2018-2019 相对高活动期
    outside += 1300 * np.exp(-((year_float - 2018.65) / 0.75) ** 2)

    # 疫情期整体降低
    pandemic_mask = dates >= pd.Timestamp("2020-01-01")
    outside[pandemic_mask] -= 2300

    # 2021 局部恢复与再次回落
    outside += 900 * np.exp(-((year_float - 2021.55) / 0.16) ** 2)
    outside -= 1000 * np.exp(-((year_float - 2021.05) / 0.12) ** 2)

    outside = np.clip(outside, 15200, 24200)

    # =========================
    # Inside China
    # =========================
    inside = (
        7900
        + 4400 * np.sin(2 * np.pi * (year_float - 2017.05))
        + 2600 * np.sin(4 * np.pi * (year_float - 2017.20))
        + 900 * np.sin(10 * np.pi * year_float)
        + rng.normal(0, 520, len(dates))
    )

    # 中国内海季节性更强，加入休渔期低谷特征
    inside -= 2400 * np.exp(-((dates.month - 6.5) / 1.2) ** 2)
    inside += 1800 * np.exp(-((year_float - 2018.65) / 0.35) ** 2)
    inside += 1600 * np.exp(-((year_float - 2021.70) / 0.20) ** 2)

    inside[pandemic_mask] -= 650
    inside = np.clip(inside, 1900, 16000)

    df = pd.DataFrame({
        "date": dates,
        "outside_china": outside,
        "inside_china": inside
    })

    return df


def generate_event_bars():
    """
    生成底部彩色短条标记。
    """

    outside_events = pd.DataFrame({
        "start": pd.to_datetime([
            "2017-01-01", "2018-01-01", "2019-01-01",
            "2020-01-01", "2021-01-01", "2021-12-01"
        ]),
        "end": pd.to_datetime([
            "2017-02-01", "2018-02-01", "2019-02-01",
            "2020-02-01", "2021-02-01", "2022-01-01"
        ]),
        "type": ["green"] * 6
    })

    inside_events = pd.DataFrame({
        "start": pd.to_datetime([
            "2017-01-15", "2018-01-20", "2019-01-20",
            "2020-01-20", "2021-01-20",
            "2017-05-01", "2018-05-01", "2019-05-01",
            "2020-05-01", "2021-05-01"
        ]),
        "end": pd.to_datetime([
            "2017-02-20", "2018-02-20", "2019-02-20",
            "2020-02-20", "2021-02-20",
            "2017-08-15", "2018-08-15", "2019-08-15",
            "2020-08-15", "2021-08-15"
        ]),
        "type": [
            "red", "red", "red", "red", "red",
            "blue", "blue", "blue", "blue", "blue"
        ]
    })

    return outside_events, inside_events


if __name__ == "__main__":
    df = generate_industrial_fishing_timeseries()
    outside_events, inside_events = generate_event_bars()

    df.to_csv("industrial_fishing_timeseries.csv", index=False)
    outside_events.to_csv("outside_event_bars.csv", index=False)
    inside_events.to_csv("inside_event_bars.csv", index=False)

    print(df.head())
```
