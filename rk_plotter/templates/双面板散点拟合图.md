一、图像类型识别与结构拆解

这是一个**双面板散点拟合图**，用于展示 MP 滞留率与水文变量、模型预测结果之间的关系。

左图 **a**：

- 图类型：散点图 + 非线性衰减拟合曲线
    
- 横轴：`River discharge (10³ m³/s)`
    
- 纵轴：`MP retention rate (%)`
    
- 数据特征：大量点集中在低流量区间，滞留率从 0–100% 高度离散
    
- 拟合形式：饱和型 / Hill 型衰减函数
    
- 拟合线：浅黄色细线
    
- 注释：非线性方程和 `R²=0.485`
    

右图 **b**：

- 图类型：预测值-观测值散点图 + 线性拟合线 + 1:1 参考线
    
- 横轴：`MP retention proportion (%)`
    
- 纵轴：`Simplified model predicted proportion (%)`
    
- 点颜色：橙色半透明散点
    
- 黑色线：`y = x`
    
- 橙色线：`y = 0.732x`
    
- 注释：`R²=0.732`，`n=225`

## 二、虚拟数据生成代码

```python
import numpy as np
import pandas as pd


def generate_panel_a_data(seed=42, n=225):
    """
    生成 panel a 的虚拟数据：
    River discharge vs MP retention rate
    """
    rng = np.random.default_rng(seed)

    # 大部分流量集中在 0-5，少量延伸到 35
    x_low = rng.gamma(shape=0.75, scale=0.9, size=int(n * 0.86))
    x_high = rng.uniform(4, 35, size=n - len(x_low))
    discharge = np.concatenate([x_low, x_high])
    discharge = np.clip(discharge, 0.02, 35)
    rng.shuffle(discharge)

    # 原图中的衰减函数。横轴单位为 10^3 m3/s，
    # 公式内部用 m3/s，因此乘以 1000
    x_real = discharge * 1000
    baseline = 0.04 + 0.83 / (1 + (x_real / 53.99) ** 0.74)

    # 低流量区强离散，高流量区逐渐接近低滞留率
    noise_scale = 0.18 * np.exp(-0.13 * discharge) + 0.025
    retention = baseline + rng.normal(0, noise_scale, n)

    # 人为加入低流量高滞留点，模拟原图左侧垂直散点云
    low_idx = np.where(discharge < 1.2)[0]
    chosen = rng.choice(low_idx, size=min(55, len(low_idx)), replace=False)
    retention[chosen] = rng.uniform(0.25, 1.0, len(chosen))

    # 增加一部分接近 0 的点
    zero_idx = rng.choice(np.arange(n), size=45, replace=False)
    retention[zero_idx] -= rng.uniform(0.06, 0.22, len(zero_idx))

    retention = np.clip(retention, 0, 1)

    df = pd.DataFrame({
        "river_discharge_10e3": discharge,
        "mp_retention_rate": retention
    })

    return df


def generate_panel_b_data(seed=7, n=225):
    """
    生成 panel b 的虚拟数据：
    MP retention proportion vs simplified model predicted proportion
    """
    rng = np.random.default_rng(seed)

    # x 大量集中在 0-0.3，少量覆盖 0.3-1.0
    x1 = rng.beta(0.8, 4.2, size=int(n * 0.72))
    x2 = rng.uniform(0.25, 1.0, size=n - len(x1))
    observed = np.concatenate([x1, x2])
    rng.shuffle(observed)

    # 预测值围绕 y = 0.732x 离散
    predicted = 0.732 * observed + rng.normal(0, 0.13, n)

    # 增加低 x 区域的垂直散布
    low = observed < 0.18
    predicted[low] += rng.gamma(shape=1.4, scale=0.08, size=low.sum())

    predicted = np.clip(predicted, 0, 1.0)

    df = pd.DataFrame({
        "mp_retention_proportion": observed,
        "predicted_proportion": predicted
    })

    return df


df_a = generate_panel_a_data()
df_b = generate_panel_b_data()

print(df_a.head())
print(df_b.head())
```

## 四、可调整参数说明

左图散点聚集程度主要由这里控制：

```python
x_low = rng.gamma(shape=0.75, scale=0.9, size=int(n * 0.86))
```

如果想让点更集中在 0 附近，可以减小 `scale`，例如：

```python
scale=0.55
```

左图拟合线由以下函数控制：

```python
y_fit = 0.04 + 0.83 / (1 + (x_real / 53.99) ** 0.74)
```

右图拟合线斜率由这里控制：

```python
0.732 * x_line
```

右图散点离散程度由这里控制：

```python
predicted = 0.732 * observed + rng.normal(0, 0.13, n)
```
