# Plot Types

Use `template-catalog.md` as the authoritative index.

## Maps
Expected data: longitude, latitude, gridded values, optional category bins, optional point overlays, optional vector fields.

## Distributions
Expected data: list of numeric arrays plus group labels.

## Scatter and Model Diagnostics
Expected data: paired numeric vectors, optional group labels, optional metrics.

## Time Series and Profiles
Expected data: ordered x values and one or more y series.

## Composition and Ranking
Expected data: category labels and component matrices.
