一、图像类型识别与结构拆解

这是一张**双面板二维热力图 / 等值填色图 / 参数响应面图**。

图中展示了不同颗粒形态下，**密度 Density** 和 **等效直径 Equivalent diameter** 对 **终端沉降速度 Terminal settling velocity** 的影响。

左图：

```text
a：Fiber
x 轴：Density，约 1100–1400 kg/m³
y 轴：Equivalent diameter，约 0.2–0.8 mm
颜色：Terminal settling velocity，约 1.94–7.86 cm/s
```

右图：

```text
b：Fragment
x 轴：Density，约 1100–1700 kg/m³
y 轴：Equivalent diameter，约 0.1–2.6 mm
颜色：Terminal settling velocity，约 0.15–16.55 cm/s
```

整体视觉特征：

- 两个子图横向排列
    
- 每个子图右侧有独立 colorbar
    
- 色带为浅米色 → 黄绿色 → 深青绿色
    
- 等值填色较平滑，但右图带有轻微横向纹理
    
- 子图编号 `a`、`b` 位于左上角
    
- 图内右下角标注颗粒形态：`Fiber`、`Fragment`

## 二、虚拟数据生成代码

```python
import numpy as np
import pandas as pd


def normalize(arr):
    """归一化到 0-1。"""
    return (arr - arr.min()) / (arr.max() - arr.min())


def generate_settling_velocity_data(seed=42):
    """
    生成用于复现图像的虚拟二维响应面数据。

    返回：
    fiber_df    : Fiber 面板数据
    fragment_df : Fragment 面板数据
    """

    rng = np.random.default_rng(seed)

    # =========================
    # Panel a: Fiber
    # =========================
    density_fiber = np.linspace(1100, 1400, 260)
    diameter_fiber = np.linspace(0.2, 0.78, 230)

    Df, Ef = np.meshgrid(density_fiber, diameter_fiber)

    x_f = normalize(Df)
    y_f = normalize(Ef)

    # 构造平滑递增响应面：密度和粒径共同提高沉降速度
    Zf_raw = (
        0.42 * x_f
        + 0.46 * y_f
        + 0.28 * x_f * y_f
        + 0.18 * y_f ** 1.8
        + 0.08 * x_f ** 1.4
    )

    Zf = 1.94 + normalize(Zf_raw) * (7.86 - 1.94)

    fiber_df = pd.DataFrame({
        "density": Df.ravel(),
        "equivalent_diameter": Ef.ravel(),
        "velocity": Zf.ravel(),
        "type": "Fiber"
    })

    # =========================
    # Panel b: Fragment
    # =========================
    density_frag = np.linspace(1100, 1720, 340)
    diameter_frag = np.linspace(0.1, 2.6, 280)

    Dg, Eg = np.meshgrid(density_frag, diameter_frag)

    x_g = normalize(Dg)
    y_g = normalize(Eg)

    # 构造更强的粒径响应，同时加入细弱横向纹理，模拟原图右图的条带感
    Zg_raw = (
        0.20 * x_g
        + 0.72 * y_g
        + 0.42 * x_g * y_g
        + 0.35 * y_g ** 1.7
        + 0.12 * x_g ** 1.3
    )

    stripe = rng.normal(0, 0.018, size=(diameter_frag.size, 1))
    Zg_raw = Zg_raw + stripe

    Zg = 0.15 + normalize(Zg_raw) * (16.55 - 0.15)

    fragment_df = pd.DataFrame({
        "density": Dg.ravel(),
        "equivalent_diameter": Eg.ravel(),
        "velocity": Zg.ravel(),
        "type": "Fragment"
    })

    return fiber_df, fragment_df


fiber_df, fragment_df = generate_settling_velocity_data()

print(fiber_df.head())
print(fragment_df.head())
```

    # Panel a: Fiber
    density_fiber = np.linspace(1100, 1400, 260)
    diameter_fiber = np.linspace(0.2, 0.78, 230)

    Df, Ef = np.meshgrid(density_fiber, diameter_fiber)

    x_f = normalize(Df)
    y_f = normalize(Ef)

    Zf_raw = (
        0.42 * x_f
        + 0.46 * y_f
        + 0.28 * x_f * y_f
        + 0.18 * y_f ** 1.8
        + 0.08 * x_f ** 1.4
    )

    Zf = 1.94 + normalize(Zf_raw) * (7.86 - 1.94)

    # Panel b: Fragment
    density_frag = np.linspace(1100, 1720, 340)
    diameter_frag = np.linspace(0.1, 2.6, 280)

        + 0.42 * x_g * y_g

    # 轻微水平条带纹理，模拟原图 b 面板中的细密横纹

    Zg_raw = Zg_raw + stripe

    Zg = 0.15 + normalize(Zg_raw) * (16.55 - 0.15)

## 四、可调整参数说明

颜色范围：

```python
levels_a = np.linspace(1.94, 7.86, 22)
levels_b = np.linspace(0.15, 16.55, 24)
```

控制两个面板的色阶数量和 colorbar 分段效果。

色带：

```python
cmap = LinearSegmentedColormap.from_list(
    "settling_velocity_cmap",
    ["#f7f0f4", "#fff4c9", "#e9dfab", "#b9c4a4", "#7d9991", "#2e6770", "#0b4f5b"]
)
```

如果想让高值更深，可把最后一个颜色改为：

```python
"#003f4a"
```

右图横向纹理强度：

```python
stripe = rng.normal(0, 0.018, size=(diameter_frag.size, 1))
```

增大到 `0.03` 会更明显，减小到 `0.005` 会更平滑。
