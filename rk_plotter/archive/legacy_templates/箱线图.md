一、图像类型识别与结构拆解

这是一张**横向多面板箱线图 / Faceted boxplot / 区域分组箱线图**。

图像结构为：

```text
1 行 × 6 列小面板
每个面板代表一个地理区域
每个面板内有 3 个国家 / 地区的箱线图
箱体为白色填充，边框、须线、离群点使用对应区域颜色
```

6 个子图分别为：

```text
Northern America：USA、CAN、GRL
Northern Africa：EGY、SDN、MAR
Rest of Europe：SRB、BIH、ALB
Eastern Europe：RUS、UKR、ROU
Central Asia：UZB、KAZ、TJK
Eastern Asia：CHN、PRK、MNG
```

视觉特征：

- 每个区域单独设置 y 轴范围，不共享 y 轴。
    
- 数据分布具有明显长尾，尤其是 `EGY、RUS、CHN`。
    
- 箱线图宽度较窄，离群点较多且点很小。
    
- 版式极度扁平，适合横向展示多个区域对比。

## 二、单独的虚拟数据生成代码

```python
import numpy as np
import pandas as pd


def sample_lognormal(median, sigma, n=220, upper=None, seed=None):
    """
    生成右偏长尾分布数据，适合复现带大量上侧离群点的箱线图。
    """
    rng = np.random.default_rng(seed)
    values = rng.lognormal(mean=np.log(median), sigma=sigma, size=n)

    if upper is not None:
        values = np.clip(values, 0, upper)

    return values


def generate_faceted_boxplot_data(seed=42):
    """
    生成 6 个区域、18 个国家的虚拟箱线图数据。
    字段：
    region  : 区域名称
    country : 国家缩写
    value   : 指标值
    """

    rng = np.random.default_rng(seed)

    config = {
        "Northern America": {
            "countries": {
                "USA": {"median": 0.047, "sigma": 0.32, "upper": 0.105},
                "CAN": {"median": 0.0035, "sigma": 0.22, "upper": 0.010},
                "GRL": {"median": 0.0005, "sigma": 0.18, "upper": 0.002},
            }
        },
        "Northern Africa": {
            "countries": {
                "EGY": {"median": 0.78, "sigma": 0.28, "upper": 2.05},
                "SDN": {"median": 0.50, "sigma": 0.25, "upper": 1.25},
                "MAR": {"median": 0.35, "sigma": 0.23, "upper": 0.95},
            }
        },
        "Rest of Europe": {
            "countries": {
                "SRB": {"median": 0.12, "sigma": 0.28, "upper": 0.36},
                "BIH": {"median": 0.035, "sigma": 0.20, "upper": 0.085},
                "ALB": {"median": 0.022, "sigma": 0.20, "upper": 0.060},
            }
        },
        "Eastern Europe": {
            "countries": {
                "RUS": {"median": 1.70, "sigma": 0.22, "upper": 3.6},
                "UKR": {"median": 0.42, "sigma": 0.20, "upper": 0.85},
                "ROU": {"median": 0.16, "sigma": 0.18, "upper": 0.35},
            }
        },
        "Central Asia": {
            "countries": {
                "UZB": {"median": 0.38, "sigma": 0.20, "upper": 0.82},
                "KAZ": {"median": 0.24, "sigma": 0.20, "upper": 0.58},
                "TJK": {"median": 0.15, "sigma": 0.20, "upper": 0.35},
            }
        },
        "Eastern Asia": {
            "countries": {
                "CHN": {"median": 2.70, "sigma": 0.20, "upper": 5.2},
                "PRK": {"median": 0.30, "sigma": 0.20, "upper": 0.75},
                "MNG": {"median": 0.035, "sigma": 0.18, "upper": 0.12},
            }
        },
    }

    rows = []

    for region, region_info in config.items():
        for country, params in region_info["countries"].items():
            vals = sample_lognormal(
                median=params["median"],
                sigma=params["sigma"],
                n=240,
                upper=params["upper"],
                seed=rng.integers(0, 1_000_000)
            )

            # 给部分国家增加少量高值离群点
            if country in ["EGY", "SRB", "RUS", "UZB", "CHN"]:
                n_out = 18
                outliers = rng.normal(
                    loc=params["upper"] * 0.72,
                    scale=params["upper"] * 0.08,
                    size=n_out
                )
                outliers = np.clip(outliers, 0, params["upper"])
                vals = np.concatenate([vals, outliers])

            for v in vals:
                rows.append({
                    "region": region,
                    "country": country,
                    "value": v
                })

    return pd.DataFrame(rows)


df = generate_faceted_boxplot_data()
print(df.head())
```
