# rk_plotter: 科研绘图模板重构 Skill

本 Skill 旨在通过**可读、可改、可交付**的完整 Python 绘图脚本服务于科学表达与模板改写流程。

---

## 核心工作原则
每次接收到科研绘图任务时，你必须：
1. **判断任务类型**：
   - **工作流 A (从 0 绘图)**: 根据数据结构选择匹配模板，复制模板代码并填入用户数据路径。
   - **工作流 B (重构旧绘图代码)**: 分离旧代码的数据逻辑和绘图逻辑，保留数据处理 block，用模板 plot() block 替换原有绘图主体。
   - **工作流 C (优化已有图)**: 原图结构合理时，仅用模板的 rcParams、配色和导出规则重写样式层。
2. **选择并阅读模板**：
   - 检查用户数据维度，对照 [template-index.md](references/template-index.md) 选择最佳模板。
   - 读取 [templates/](templates/) 目录下的对应 `.py` 脚本，以其代码为**母版**进行改写。
3. **模板母版与受控扩展**：
   - **不改变图形基本形式，不等于不能添加元素**：只要科学数据或分析逻辑需要，允许在模板风格体系内增加同类坐标轴、数据系列、误差线、参考线、简要统计注释和局部 inset 放大图。
4. **显式数据绑定**：
   - 使用 `FIELD_MAP` 绑定实际列名，禁止直接使用列索引（如 `iloc[:, 0]`）强行猜测数据科学含义。
5. **输出完整脚本**：
   - 最终交付给用户的必须是**完整、独立运行**的脚本，不能只给出 diff 片段或黑盒函数调用。

---

## 🚫 禁止事项与文本控制
除非用户明确要求，否则禁止：
- 改变基本图形类型（如把散点图改柱状图）。
- 改变基本面板/子图的总体布局结构。
- 删除模板中的 colorbar、legend、参考线、误差带或 panel 标签（A/B/C/D）。
- **使用虚拟/示例数据**：模板代码中提供的示例数据生成逻辑仅用于模板预览与测试。在为用户编写真实绘图脚本时，**必须完全替换为用户真实的输入数据**，严禁调用或残留任何随机生成的虚拟/模拟数据。
- **依赖缺失时回退或降级**：当绘图依赖缺失时（例如未安装 `cartopy`），必须自动安装或报错提示安装，**严禁使用非地图投影等降级形式进行回退**，必须确保图形基本形式与母版的一致性。
- **过度添加文字注释**：在图中添加过多的文字注释会破坏学术美感。图内注释必须保持极简，一般只允许包含：
  - 显著性符号（如 `*`、`**`、`***`、`n.s.`）。
  - 回归分析统计参数（如斜率、$R^2$、回归方程、$p$ 值、$N$ 等）。
  - 必要的简短数据标签，避免长句或冗余文本。
- 只输出 PNG，不输出 SVG/PDF 矢量图。
- 遗留交互式 blocking 语句 `plt.show()`。
